# AI & Machine Learning Documentation

This directory contains specifications, pipelines, prompts, and evaluation methodologies for the **PathForge AI** recommendation and gap analysis service (`services/ai`).

## Documented Topics (Planned)

* **Skill Taxonomy & Embedding Models:** Vector embeddings for career profiles, skill definitions, and learning resources.
* **Skill Gap Analysis Engine:** Algorithmic comparison of learner skill vectors against target career graphs.
* **Adaptive Roadmap Generator:** Dynamic generation and reprioritization of learning milestones based on quiz/project progress.
* **Explainability Pipeline:** Structured reasoning chains explaining why each learning resource or project was assigned.
* **Prompt Engineering & Validation:** Structured output constraints, Pydantic validation schemas, and LLM provider abstractions.
