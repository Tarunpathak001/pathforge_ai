# Architecture Documentation

This directory contains system architecture specifications, high-level component diagrams, data flow models, and infrastructure topology for **PathForge AI**.

## Documented Topics (Planned)

* **System Overview & Component Boundaries:** Relationships between `apps/web`, `apps/api`, and `services/ai`.
* **Data Flow & Communication Protocols:** REST API contracts, background worker task dispatching, and AI pipeline orchestration.
* **Database & Entity Relationship Models:** Schema models for learners, skill graphs, career goals, and roadmaps.
* **Deployment & Infrastructure Topology:** Docker containerization, Redis caching layers, and production host configuration.
