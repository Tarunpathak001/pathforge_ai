# API Documentation

This directory contains specifications and contract references for the **PathForge AI** REST API (`apps/api`).

## Documented Topics (Planned)

- **OpenAPI / Swagger Specifications:** Formal API contracts for all endpoints.
- **Authentication & Authorization:** JWT token flows, role permissions, and session management.
- **Endpoint Catalog:** Route definitions, request payloads, response schemas, and status codes for:
  - Learner profiles and onboarding
  - Skill assessments and gap analysis
  - Roadmap generation and milestone progress tracking
  - Recommendation explainability queries
- **Error Handling & Standard Responses:** Unified JSON error envelope formats.
